# Local fonts

All font files are served from this repository. No Google Fonts stylesheet,
preconnect, or third-party font requests are needed at runtime.

- Inter variable (normal, weights 100–900):
  https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2
- JetBrains Mono (normal, Regular/400, Medium/500, SemiBold/600):
  https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts

Downloaded on 2026-11-07. Both families use the SIL Open Font License 1.1;
each font directory contains its upstream license. Keep those licenses with
the font files when redistributing them.
